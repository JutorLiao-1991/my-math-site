從拆數、代入公式到算出答案，逐列完成三個最常用的乘法公式。

和的平方
(a + b)2 = a2 + 2ab + b2
適合接近整十、整百的平方
差的平方
(a − b)2 = a2 − 2ab + b2
中間項一定是減號
平方差
a2 − b2 = (a + b)(a − b)
先和、再差，直接相乘
